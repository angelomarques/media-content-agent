# Media content agent

Skills for creating media with AI. Cursor loads them from `.cursor/skills/` in this project.

## Skills

- **image-prompt** — Writes a narrative prompt for AI image generation and editing. The method follows Google's Gemini image prompting guide: describe the scene, then fill a template for the job (photo, sticker, text, product, minimal layout, comic panel, edit, inpaint, style transfer, or a combination of reference images).
