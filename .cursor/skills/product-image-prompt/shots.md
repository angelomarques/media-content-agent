# Product shot templates

Fill the matching section as one paragraph. Drop a slot only when the user ruled it out. Examples are quality targets, not text to reuse.

Shots after the master start with "Using the provided master image of {product}" and include the lock from the skill: same silhouette, proportions, materials, color, hardware, logos, and construction. Say which of those the shot is allowed to change.

## Master

A high-resolution, studio-lit product photograph of a {product, with material and finish} on a {surface}. It is the hero image for a {product page or ad}. The lighting is a {setup} to {purpose}. The camera angle is a {angle} to showcase {feature}. Ultra-realistic, with sharp focus on {detail}. {Aspect ratio}.

If they attached a product photo and asked to polish it, start with "Relight the product in the provided image" and keep identity, markings, and proportions. That photo is the master. Do not describe a different object.

Example:

```text
A high-resolution, studio-lit product photograph of a matte sand insulated bottle with a black screw lid, standing on pale limestone. It is the hero image for a product page. The lighting is a three-point softbox setup to give a soft highlight along the lid edge and a faint contact shadow. The camera is a slightly elevated 45-degree view to show the slim profile and the lid threads. Ultra-realistic, with sharp focus on the lid gasket. Square.
```

## Flat lay

Using the provided master image of {product}, create a top-down, neatly arranged flat-lay photograph. Place the exact product from the image alongside {each included item}. The items sit on a {surface}. The product keeps the same silhouette, proportions, materials, color, hardware, logos, and construction. {Aspect ratio}.

List only items they named, or parts the product obviously separates into. This shot is for an unboxing or "what's in the box" module.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a top-down, neatly arranged flat-lay photograph. Place the exact bottle from the image alongside its black screw lid, a clear glass straw, and a sand fabric sleeve. The items sit on warm oak with even gaps between them. The bottle keeps the same silhouette, proportions, matte sand body, black lid, and unmarked face. It is the unboxing image for the product page. Square.
```

## Macro

Using the provided master image of {product}, reframe the shot as an extreme macro photograph. Focus exclusively on the {feature}, so that detail is the hero. Keep the lighting and style of the master, and keep the same materials, color, hardware, and construction. {Aspect ratio}.

One feature only.

Example:

```text
Using the provided master image of the matte sand insulated bottle, reframe the shot as an extreme macro photograph. Focus exclusively on the lid gasket, so the dark ring and the first threads fill the frame. Keep the soft studio light and the matte sand body from the master, with the same black lid and unmarked face. It is a detail image for the product page. Square.
```

## Colorways

Using the provided master image of {product}, create a single composite showing the original product side by side with {variation 1} and {variation 2}, on a clean {background}. Same angle, same scale, same light. Change only the named finish. Silhouette, proportions, hardware, logos, and construction stay identical. {Aspect ratio}.

Use only finishes they named.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a single composite showing the original sand bottle side by side with a matte fog-gray version and a matte clay version, on a clean warm-white ground. Same 45-degree angle, same scale, same softbox light. Change only the body color. The black screw lid, slim profile, and unmarked face stay identical. It is a colorway module for the product page. Square.
```

## Scale

Pick the branch that matches the product.

Wearable: Using the provided master image of {product}, create a single composite showing it on three {feet or bodies}: one small, one medium, and one large. The shots share one angle so the fit compares directly. The product's silhouette, materials, color, logos, and construction stay identical in every panel. {Aspect ratio}.

Object: Using the provided master image of {product}, create a single composite showing it at true scale beside {three familiar references, or in a small, medium, and large hand}. Same angle in every panel. The product stays identical. {Aspect ratio}.

This shot is a fit guide or a size guide. It exists to prevent returns.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a single composite showing it at true scale in a small hand, a medium hand, and a large hand. All three panels use the same 45-degree angle. The bottle keeps the same slim profile, matte sand body, black screw lid, and unmarked face. It is a size guide for the product page. Square.
```

## In use

Using the provided master image of {product}, create a close-up photograph of {a specific person} actively using it. The focus is on {the action}, demonstrating {one feature}. The product keeps the same silhouette, proportions, materials, color, hardware, logos, and construction. {Aspect ratio}.

If Image 2 is a model, that image supplies the person's identity. The master remains the product.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a close-up photograph of a woman in her thirties with a short black crop and a linen shirt, twisting the lid open with one hand. The focus is on the lid turning, demonstrating the gasket seal. The bottle keeps the same slim profile, matte sand body, black lid, and unmarked face. It is an in-use still for the product page. Vertical 4:5.
```

## Lifestyle

Using the provided master image of {product}, create a photorealistic lifestyle scene. {The same person from the in-use shot, or the person described here} is {wearing or using} the product while {action} in {location}. The lighting and mood are {light and mood}. The product keeps the same silhouette, proportions, materials, color, hardware, logos, and construction. {Aspect ratio}.

Build the room in the prompt. Do not ask for a separate background plate.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a photorealistic lifestyle scene. The same woman with the short black crop and linen shirt drinks from the bottle while walking a shaded city sidewalk in late afternoon. Warm side light and a calm, unhurried mood, with the storefronts behind her in soft blur. The bottle keeps the same slim profile, matte sand body, black lid, and unmarked face. It is a campaign still for the product page. Landscape 16:9.
```

## UGC

Using the provided master image of {product}, generate a realistic user-generated photo of it in {an everyday situation}. The picture looks like a high-quality smartphone photo, slightly casual, with natural light. The product keeps the same silhouette, proportions, materials, color, hardware, logos, and construction. {Aspect ratio}.

A different person from the brand model. Everyday place, not a studio.

Example:

```text
Using the provided master image of the matte sand insulated bottle, generate a realistic user-generated photo of it on a kitchen counter beside a half-made lunch. A different person, a man in a faded t-shirt, holds it loosely in one hand. The picture looks like a high-quality smartphone photo, slightly off-center, with daylight from a nearby window. The bottle keeps the same slim profile, matte sand body, black lid, and unmarked face. It is a social post meant to feel like a customer photo. Vertical 4:5.
```

## Banner

Using the provided master image of {product}, create a minimalist composition with the product in the {corner or edge} of the frame. The background is a {field}, leaving a large empty {region} for a headline. The product keeps the same silhouette, proportions, materials, color, hardware, logos, and construction. {Aspect ratio}.

Leave the empty region blank unless they gave final copy. When they did, quote each line, name the type, and say the words appear once.

Example:

```text
Using the provided master image of the matte sand insulated bottle, create a minimalist composition with the bottle in the lower-right of the frame. The background is a flat warm-ivory field, leaving a large empty left half for a headline. Soft light from the upper left, with a faint contact shadow only. The bottle keeps the same slim profile, matte sand body, black lid, and unmarked face. It is an ad background. Landscape 16:9.
```

## Shop the look

Create a new composite product photo by combining the items from the provided images. Take {the product in Image 1}, {the product in Image 2}, and {the product in Image 3}. Arrange them in a {flat lay or other named arrangement} on a {surface}. Each object keeps the silhouette, materials, color, and markings of its own image. {Aspect ratio}.

One attached image per product. If a companion image is missing, ask for it. Do not describe stand-in products.

Example:

```text
Create a new composite product photo by combining the items from the provided images. Take the matte sand bottle from Image 1, the linen cap from Image 2, and the small canvas pouch from Image 3. Arrange them in a clean top-down flat lay on warm oak, with even gaps. Each object keeps the silhouette, materials, color, and markings of its own image. It is a shop-the-look module for the product page. Square.
```
